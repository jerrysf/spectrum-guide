# 内容规范与循证标准

## 1. 内容原则

- **循证为主**：优先引用同行评审文献、权威机构指南（如 AAP、CDC、NICE、WHO、国内中华医学会相关共识）。区分"已有较好证据"、"实践中常用"、"证据不足或存在争议"。
- **通俗实用**：面向无专业背景的读者，使用简体中文，句子短，先结论后解释，配具体生活例子。
- **尊重个体**：使用"自闭症谱系障碍/谱系人士"等中性表述；不把儿童描述为需要被"修复"的对象；尊重神经多样性视角。
- **不夸大**：不使用"治愈""恢复正常""根治"等表述；不推荐缺乏证据的疗法（如螯合疗法、未经验证的生物疗法等）。
- **保守措辞**：结论不确定时明确说明不确定性，并标记为需要专业复核。

## 2. 必须区分四个概念

| 概念 | 含义 | 本站定位 |
| ---- | ---- | -------- |
| 医学诊断 | 由具备资质的医疗机构按 DSM-5/ICD-11 等标准做出 | 本站不做诊断 |
| 初步筛查 | 标准化工具提示是否需要进一步评估 | 仅介绍，不自行计分 |
| 发展能力观察 | 家长/教师在日常情境中记录孩子能力 | 本站工具属于此类 |
| 教育干预 | 教学与家庭支持策略 | 本站课程属于此类 |

## 3. Frontmatter 审核字段

- `reviewStatus`：`draft` → `needs_review` → `reviewed` → `published`。只有 `published` 对外可见。
- `reviewerRole`：如"编辑整理，待专业审核"。**没有实际专业人员参与审核时，禁止写"医生审核""专家审核"。**
- `sources`：每条含 title、author（机构或作者）、year、url、type（guideline / review / book / official_page 等）。**禁止伪造文献与链接。**

## 4. 发布检查清单

- [ ] 医学相关论述附有真实可查的参考来源
- [ ] 未给出诊断结论或用药建议
- [ ] 未编造国内政策、医院信息、医保待遇、诊疗流程
- [ ] 危险行为相关内容提示个体化专业评估与紧急求助
- [ ] 干预方法不含惩罚、恐吓、强迫眼神接触、剥夺沟通方式等内容
- [ ] 儿童相关示例不含可识别的真实个人信息
- [ ] 外部链接有效且指向可信来源

## 5. 纠错流程

文章详情页提供"内容纠错"入口（链接至 `/about` 的联系邮箱）。收到纠错后：核实 → 修改 → 更新 `lastUpdated` → 重新审核。
