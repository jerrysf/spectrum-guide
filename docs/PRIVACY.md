# 隐私与数据保护规范

## 1. 第一版原则

- 默认不要求登录，不收集实现功能所不必要的个人信息。
- 不默认收集儿童敏感信息：真实姓名、身份证号、面部照片、学校名称、精确地址均不收集。
- 本站无服务端数据提交，无第三方分析服务。

## 2. 发展能力观察数据

- 观察回答默认只在当前浏览器内存中处理。
- 用户明确勾选"保存在此浏览器"后才写入 `localStorage`；页面提供"清除已保存数据"操作。
- 观察回答不进入 URL、查询参数、错误报告或任何日志。
- 页面明确说明：数据仅保存在当前浏览器，清除浏览器数据后会丢失；打印功能不需要上传服务器。

## 3. 搜索与 URL

- 搜索结果可通过 `?q=&category=` 等查询参数分享；查询参数中不得放入儿童个人信息或观察回答。

## 4. 安全要求

- 所有用户输入经 Zod/框架校验，防止 XSS 与不安全的文件路径；MDX 不渲染原始 HTML。
- API 密钥与数据库凭据只放环境变量，`.env.example` 只含占位符。
- 外部链接在内容审核时人工核验。
- 未来引入用户数据 API 时：服务端身份与权限检查为前置条件；Supabase 必须启用 RLS。

## 5. 未来功能的前置要求

- 观察历史/账号：需数据加密、删除机制、最小化收集、未成年人数据特别保护评估。
- 社区：需内容审核、举报、儿童个人信息识别与拦截规则。
- 机构名录：需机构授权与撤下机制。
