# 星伴成长（Spectrum Guide）产品需求文档

## 1. 产品定位

面向中国大陆自闭症儿童家长、特殊教育教师、康复师及普通用户的循证知识与实操平台。

核心理念：

- 循证为主，尊重个体差异。
- 语言通俗，可直接用于日常生活与教学。
- 明确区分医学诊断、初步筛查、发展能力观察与教育干预。
- 不宣称治愈自闭症，不宣传缺乏可靠证据的疗法。
- 优先保护儿童隐私。

## 2. 用户角色

| 角色 | 主要诉求 |
| ---- | -------- |
| 家长 | 理解自闭症、观察孩子发展、获取家庭干预方法、就诊准备 |
| 特教老师 | 教学策略、课堂支持、家校协作工具 |
| 康复师 | 实操方法、记录工具、循证参考 |
| 普通用户 | 基础认知、消除误解 |

## 3. MVP 范围

### 包含

- 首页：产品入口，搜索、分类入口、热门内容、循证原则、安全指南入口
- 科普知识库 `/knowledge`：MDX 文章，12 篇种子内容，含审核状态与参考来源
- 发展能力观察 `/assessment/development`：非诊断性观察工具，本地处理、可选 localStorage 保存、打印友好结果
- 干预课程 `/courses`：8 门结构化实操课程
- 资源下载 `/resources`：8 个真实可打印模板（HTML 打印页）
- 安全指南 `/safety`：自伤、走失/跑离、情绪危机 3 篇
- 全站搜索 `/search`：本地结构化内容搜索，URL 查询参数可分享
- 专区页 `/parent-guide`、`/professional`
- 机构名录 `/directory`：明确的"筹备中"状态与规划说明，不含虚构机构数据
- 关于页 `/about`、循证标准 `/about/evidence`、隐私政策 `/about/privacy`、免责声明 `/about/disclaimer`
- SEO：metadata、sitemap、robots.txt、结构化数据、404

### 不包含（后续版本）

- 用户认证、`/account`、`/bookmarks`
- 观察历史 `/assessment/history`
- 社区 `/community`
- 机构名录真实数据
- 标准化筛查量表接入（M-CHAT、ABC、CARS 等需授权与专业审核后接入）

## 4. 验收标准

- `npm install` 后可 `npm run dev` 启动，`npm run build` 构建成功。
- 所有导航链接指向有效页面，无死链。
- 首批内容完整可读，非占位符。
- TypeScript 检查、ESLint、Vitest、Playwright 核心流程全部通过。
- 发展观察工具不输出诊断结论，不将回答转为医学风险评分。
- 资源文件真实存在且可下载/打印。
- 未实现功能有明确"筹备中"标记，不以空白页伪装上线。
