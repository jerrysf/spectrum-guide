与其在行为发生后"灭火"，不如通过观察和调整环境让行为更少发生。这门课教你做简单的功能性观察。

## 第一步：定义要观察的行为

把模糊的"闹""不配合"变成可观察的描述：

- ❌"不听话" → ✅"大人提出收玩具后，孩子躺下、尖叫、用手推开玩具筐"；
- ❌"攻击人" → ✅"排队等待超过约 1 分钟时，会抓旁边人的胳膊"。

定义要具体到"换一个人来看描述，就知道该记什么"。

## 第二步：连续记录 ABC

每次发生就记一行（用[ABC 观察表](/resources/abc-observation-sheet)）：

- **前因**：时间、地点、之前 5 分钟发生了什么、身体状态（饿/累）、感官环境（吵/挤）；
- **行为**：具体动作、强度、持续时间；
- **结果**：大人做了什么，孩子得到/逃避了什么。

连续记录 1–2 周，或至少 8–10 次事件。

## 第三步：找模式与假设功能

翻看记录找规律：

- **时间/情境规律**：总是发生在饿了、转换、嘈杂、被提要求时？
- **结果规律**：每次发生后，孩子是不是都"不用做那件事了"或"得到了关注/东西"？

常见功能假设：逃避任务、获得关注、获得物品、感官调节、身体不适。

## 第四步：从功能倒推环境调整

| 如果功能是 | 试试这些环境调整 |
| ---- | ---- |
| 逃避太难/太长的任务 | 拆小任务、降低难度、先做一点再休息、预告"做 X 个就结束" |
| 获得关注 | 平时多主动给关注；行为发生时保持平静、简短回应；教"用说的要关注" |
| 获得物品/活动 | 建立明确的规则与预告；教用沟通方式提出请求；不在爆发后给 |
| 感官负荷 | 降噪、减少视觉杂乱、安排感觉餐、提供感觉出口 |
| 身体不适 | 排查睡眠、便秘、疼痛；教孩子表达不舒服的方式 |

## 第五步：验证与迭代

- 调整后继续记录，看频率/强度是否下降；
- 没变化说明功能假设可能错了，回记录里重新找模式；
- 一次只调整一两个变量，否则不知道哪个起作用。

## 重要边界

- 这个方法对**日常高频、低危险**的行为最有效；
- 涉及自伤、攻击、跑离等危险行为时，观察的同时请先保证安全（见[安全指南](/safety)），并寻求行为分析师（BCBA）或临床心理/精神科专业人员的个体化功能评估——复杂行为的功能常常是多重的，需要专业判断。
