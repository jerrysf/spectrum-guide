孩子在超市突然倒地尖叫、因为换了一条回家路线而崩溃、被叫到名字时大发脾气——这些时刻常被旁观者理解为"没家教""被惯坏"，但对谱系孩子来说，情绪爆发几乎总是有原因的。

## 情绪爆发 ≠ 发脾气

- **发脾气（tantrum）**通常有观众、有目标，孩子会在过程中"看效果"。
- **情绪爆发（meltdown）**是负荷超过承受能力后的失控，没有观众也会发生，孩子此时已失去自我调节能力，讲道理、威胁、奖励都不起作用。

把爆发当作"求救信号"而不是"服从问题"，是理解的第一步。

## 用 ABC 思路找原因

行为分析中常用的 **A-B-C** 框架：

- **A（Antecedent，前因）**：爆发之前发生了什么？环境（太吵、人多、太热）、任务（太难、突然变化）、身体状态（饿了、累了、生病）？
- **B（Behavior，行为）**：具体做了什么？哭喊、倒地、扔东西、跑开、伤害自己？
- **C（Consequence，结果）**：之后发生了什么？大人给了什么反应？孩子得到了什么/逃避了什么？

连续记录几次后（可用[ABC 行为观察表](/resources/abc-observation-sheet)），常见的功能会浮现：

| 可能的功能 | 典型线索 |
| ---- | ---- |
| 逃避/回避 | 多发生在被要求做某事之后，爆发后任务被取消 |
| 获得关注 | 大人忙于别的事时容易发生，爆发后获得大量关注 |
| 获得物品/活动 | 想要某物被拒绝后爆发，曾因爆发得到过 |
| 自我刺激/感官 | 无论情境都出现，或与无聊、感官负荷相关 |
| 身体不适 | 没有明显规律，伴随生病、睡眠差、便秘等 |

## 爆发时的现场原则

1. **先保安全**：移开危险物品，把孩子带到相对安静安全的位置（参见[情绪危机安全指南](/safety/emotional-crisis)）。
2. **少说话**：此时语言处理是超载的，用简短平静的词（"我在这""安全"）或直接陪伴。
3. **不讲道理、不惩罚、不讨价还价**。
4. **守住底线但态度平静**：危险行为要挡，但用身体阻隔和引导，而不是吼叫。
5. **事后不追责**：孩子平静后简单安抚，稍后再回顾；不要在事后长篇说教。

## 爆发前的预防更关键

- 找出并减少诱发因素：预告变化、拆分任务、降低感官负荷（见[感官敏感](/knowledge/sensory-sensitivity)）。
- 教孩子替代表达方式：用图片、手势或词语表达"要休息""不要""帮我"（见[功能性沟通课程](/courses/functional-communication)）。
- 规律作息、保证睡眠和运动——身体状态是所有调节能力的基础。

## 需要专业帮助的信号

- 爆发频繁到影响上学、出门等日常功能；
- 出现伤害自己或他人的行为（见[自伤安全指南](/safety/self-injury)）；
- 你怀疑有疼痛或躯体不适但孩子无法表达。

这些情况建议寻求行为干预或心理专科的个体化评估。
