自闭症谱系障碍（Autism Spectrum Disorder，ASD，也常译作"孤独症"）是一种神经发展状况。它影响一个人与他人沟通互动的方式、处理感觉信息的方式，以及行为与兴趣的模式。

## 为什么叫"谱系"

"谱系"的意思是：自闭症在每个具体的人身上表现得非常不一样。

- 有的孩子语言发展明显落后，有的孩子说话很早但难以维持对话。
- 有的人需要全天候支持，有的人可以独立生活、工作。
- 有的人对声音、光线特别敏感，有的人会主动寻求强烈的感觉刺激。

所以，"这个孩子是自闭症"并不能告诉你"这个孩子具体是什么样"。了解一个具体的谱系孩子，永远比记住一个标签更重要。

## 两个核心特征

按照目前通行的诊断框架（DSM-5、ICD-11），自闭症的核心特征可以概括为两大类：

1. **社交沟通与互动的持续困难**：比如难以发起或维持对话、较少用表情手势分享情绪、不太能跟随社交情境中的潜规则。
2. **局限、重复的行为、兴趣或活动模式**：比如重复的动作、对固定程序的强烈需要、狭窄而强烈的兴趣，以及感官上的异常敏感或寻求。

这些特征通常在生命早期就能观察到，但被发现的时间因人而异，有些人直到成年才被识别。

## 关于成因：目前知道什么

- 研究认为自闭症与**遗传因素**关系很大，是多种因素共同影响大脑发育的结果。
- **明确的共识**：疫苗不会导致自闭症。相关"研究"早已被证实造假并撤稿，大规模研究反复否定了这一关联。
- 自闭症不是父母教养方式造成的。"冰箱妈妈"之类的说法早已被科学否定。

## 几个常见误解

| 误解 | 事实 |
| ---- | ---- |
| 自闭症孩子都不会说话 | 约三分之一的谱系人士口语很少或没有口语，但许多人有语言；不说话不等于不理解、不想沟通 |
| 自闭症都是"天才" | 少数人有突出的特殊能力，多数孩子是普通孩子，有自己的优势和困难 |
| 自闭症可以"治愈" | 它是神经发展的一部分，伴随终身；干预的目标是提升生活质量和功能，而不是"变成不是自闭症" |
| 自闭症是近年才流行的"新病" | 检出率上升主要与认识提高、诊断标准放宽、服务可及性改善有关 |
