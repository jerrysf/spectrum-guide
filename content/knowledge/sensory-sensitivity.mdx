捂耳朵、拒绝某种质地的衣服、只肯吃几样食物、不停地转圈或蹦跳——这些常被理解为"行为问题"的表现，背后常常是**感官处理的差异**。

## 什么是感官处理差异

我们的大脑不断接收来自视觉、听觉、触觉、嗅觉、味觉，以及本体感觉（身体位置）和前庭觉（平衡、运动）的信息，并把它们调节到"合适"的程度。很多谱系孩子的调节方式与常人不同，常见两种模式：

- **过度敏感（低反应阈值）**：普通强度的刺激对孩子来说太强烈——吹风机的声音像轰鸣，衣服标签像针扎。
- **感觉寻求或低敏感**：刺激不够就难受——不停地动、用力碰撞、盯着旋转的东西看、喜欢很深的拥抱或按压。

同一个孩子可能在不同感觉通道上既有敏感又有寻求，反应也会随状态（累、饿、紧张）变化。

## 常见表现对照

| 场景 | 表面看到的行为 | 可能的感官原因 |
| ---- | ---- | ---- |
| 商场/食堂里烦躁、捂耳、想离开 | "不听话、闹情绪" | 声音与人群刺激超载 |
| 拒绝理发、剪指甲、刷牙 | "不配合" | 头皮、指甲、口腔触觉敏感 |
| 只吃少数几种食物 | "挑食" | 对质地、味道、温度敏感 |
| 不停地跑跳、撞沙发 | "多动、调皮" | 前庭与本体感觉寻求 |
| 盯着旋转的风扇看很久 | "怪异行为" | 视觉寻求，或旋转带来安抚 |
| 情绪突然崩溃 | "莫名其妙发脾气" | 累积的感官负荷超过承受限度 |

## 环境可以怎样调整

基本原则：**减少不必要的难受刺激，提供安全合规的感觉出口**。

- 听觉：在嘈杂环境备用耳塞/降噪耳机；提前告知"等下会有很响的声音"。
- 视觉：减少频闪与杂乱；需要时用隔板、帽子降低视觉负荷。
- 触觉：剪掉标签、选宽松柔软的衣物；理发、刷牙这类活动拆成小步骤慢慢适应。
- 感觉寻求：在日程中安排蹦床、推拉重物、深压拥抱（孩子接受的前提下）等"感觉餐"，而不是一味制止。
- 预警与缓冲：活动转换前给预告和缓冲时间，避免感觉负荷突然叠加。

## 什么时候需要专业帮助

- 感官反应严重影响吃饭、睡觉、上学等日常功能；
- 出现撞头等可能存在风险的自我刺激（参见[安全指南](/safety/self-injury)）；
- 想系统了解孩子的感官特点——作业治疗师（OT）可以做标准化评估并制定个体化"感觉餐"方案。

<Callout type="info">感官处理差异是谱系孩子的核心特征之一，已写入 DSM-5 的诊断标准。把"闹"重新理解为"难受"，是改变支持方式的第一步。</Callout>
