"孩子说话晚"是家长最常见的担心之一。语言发育迟缓和自闭症都可能表现为"说话少"，但两者的底层情况不同，区分它们有助于找到正确的支持方向。

## 关键区别不只在"说多少"，更在"沟通意愿"

**单纯语言发育迟缓的孩子**通常有强烈的沟通意愿，会用手势、表情、声音"补偿"口语不足：

- 拉你的手带你去要的东西那里；
- 用手指指着想要的东西，同时看你，确认你明白；
- 用表情、点头摇头、咿呀声跟你"对话"；
- 喜欢模仿大人的动作，喜欢玩轮流游戏。

**有自闭症特质的孩子**可能在口语之外，沟通意愿和方式也不同：

- 较少用指物、展示等方式主动分享；
- 非语言沟通（手势、表情、眼神配合）整体偏少，不只是口语少；
- 对别人说话的回应不稳定；
- 常伴随重复行为、固定程序或明显的感官特点。

## 一张对比表

| 维度 | 单纯语言发育迟缓 | 需要留意的自闭症相关表现 |
| ---- | ---- | ---- |
| 沟通意愿 | 强，想尽办法表达 | 可能偏弱或方式不同 |
| 非语言沟通 | 丰富（指、拉、表情） | 整体偏少 |
| 听懂程度 | 常好于会说（理解>表达） | 理解也可能落后或不稳定 |
| 模仿 | 喜欢模仿 | 模仿可能较少 |
| 社交兴趣 | 想和人玩 | 对人兴趣少或不知如何加入 |
| 行为模式 | 一般灵活 | 可能有重复行为、强烈固定程序 |
| 感官 | 一般正常 | 可能有明显敏感或寻求 |

## 两种情况可能同时存在

需要注意：自闭症孩子几乎都有语言沟通方面的发展差异，所以"既有语言迟缓又有自闭症"很常见；而只有语言迟缓、社交沟通其他方面都灵活的孩子，则可能只是语言问题本身。

## 家长可以做什么

- 无论哪种情况，**早期支持都有帮助**。不必等"确诊"才开始帮助孩子沟通，从[功能性沟通课程](/courses/functional-communication)做起。
- 记录孩子"用什么方式沟通"：手势、拉人、发音、词语、图片。这对评估很有帮助。
- 2 岁左右仍没有任何口语、或 3 岁仍不会说简单短句，建议评估；如果同时有上述社交与行为表现，建议尽快咨询发育行为科，而不是"再等等看"。

<Callout type="warning">语言迟缓有多种可能原因（听力、语言环境、发展性语言障碍、自闭症等），只有专业评估才能区分。本文帮助你观察记录，不能替代评估。</Callout>
